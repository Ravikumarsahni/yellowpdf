Honesty note in UI: pdf-lib does NOT write native PDF encryption. Implementation: re-saves the PDF through pdf-lib, then encrypts the bytes with AES-GCM (256-bit, 12-byte IV) via `crypto.subtle`, key derived from the user password via PBKDF2 (SHA-256, 100k iterations, 16-byte random salt).    114→12. `unlock-pdf.tsx` — `UnlockPdfTool`: accepts `.pdf` OR `.pdf.enc`. On wrong password catches the thrown exception and shows a clean error. For plain `.pdf`, just calls `loadPdf` (which uses `ignoreEncryption: true` per the wrapper default) and re-saves to strip the encryption flag. Includes an honesty note that "open-password" PDFs aren't natively supported by pdf-lib — those users should use the Protect PDF + Unlock PDF pair. Output `unlocked.pdf`.
